# Gestor de Tareas (Frontend)

Interfaz de usuario para la API de tareas, desarrollada con **React** y **Vite**. Permite crear, listar, marcar como completada y eliminar tareas.

## Funcionalidades

- Visualización de tareas con indicador de carga.
- Añadir nuevas tareas.
- Marcar tareas como completadas o pendientes.
- Eliminar tareas.
- Manejo de errores con mensajes visibles.
