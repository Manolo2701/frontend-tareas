# Gestor de Tareas — Frontend

Aplicación web para la gestión de tareas, desarrollada con **React** y **Vite**, conectada a una API REST desarrollada con **Node.js** y **Express**.

## Tecnologías

- React
- Vite
- JavaScript
- CSS
- Node.js
- Express
- API REST

## Funcionalidades

- Visualización de tareas.
- Creación de nuevas tareas.
- Marcado de tareas como completadas o pendientes.
- Eliminación de tareas.
- Indicador de carga durante las peticiones.
- Gestión y visualización de errores.

## Arquitectura

El proyecto está dividido en dos partes:

- **Frontend:** aplicación React desarrollada con Vite.
- **Backend:** API REST desarrollada con Node.js y Express.
